# Действующий контракт

GET /api/records без параметров: 200, все записи по id.
Параметр end: одна дата YYYY-MM-DD; записи с date меньше либо равной end.
Поля: id (целое), title (строка), date (YYYY-MM-DD).
Нет совпадений: 200 и []. Ошибочная дата, пустой/повторный end или неизвестный параметр: 400 JSON.
Недоступный/невалидный файл данных: 500, {"error":"data_unavailable"}.
GET /health: 200 с status=ok при читаемых данных; 503 при отказе данных.
Изменение контракта в этой работе не требуется.
