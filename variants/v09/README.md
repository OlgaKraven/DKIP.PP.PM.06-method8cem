# Стенд варианта 09

Автоматизация планирования бизнес-процесса (указать конкретный) с использованием технологии искусственного интеллекта

.NET SDK 10, Python 3 для отдельного тестового проекта.
Распаковать в свою рабочую папку. Открыть PowerShell в ней: `dotnet run --urls http://127.0.0.1:5186`. Открыть тот же адрес в браузере.
Исходные данные: data.json; контроль: context.json; действующий контракт: contract.md.
Порядок диагностики, изменения и восстановления — в методических рекомендациях.
