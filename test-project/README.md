# Отдельный тестовый проект

Python 3, без дополнительных пакетов. Скопировать baseline.cases.json своего стенда как cases.json.
Из папки тестового проекта: `py -3 check.py http://127.0.0.1:5186 cases.json`.
Для нового случая добавить объект с name, path, status и ids (ожидаемые id).
Сохранять вывод до и после исправления. Обязательный граничный случай описан в методичке и карточке варианта.
